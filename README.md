# Customer Churn Analysis & Prediction

## Project Overview
This project analyzes customer churn for a telecommunications company using MySQL, Excel, Power BI, Python, and Machine Learning. It explores customer behavior, identifies churn patterns, and predicts potential customer churn using a Random Forest model.

## Objectives
- Analyze customer demographics, contracts, and revenue.
- Clean and validate customer data using SQL.
- Build an interactive Power BI dashboard for churn analysis.
- Develop a Random Forest model to predict customer churn.
- Present business insights to support customer retention.

## Tools & Technologies
- **MySQL:** Database creation, data cleaning, SQL queries, and views.
- **Excel:** Data inspection and preparation.
- **Power BI:** Interactive dashboards and KPI visualization.
- **Python:** Data preprocessing and machine learning.
- **Pandas & Scikit-learn:** Data analysis and Random Forest modeling.
- **Jupyter Notebook:** Model development and experimentation.
